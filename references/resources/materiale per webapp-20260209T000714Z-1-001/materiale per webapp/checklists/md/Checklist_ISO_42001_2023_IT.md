# Checklist Integrata Gap Analysis ISO/IEC 42001:2023

> Checklist basata sulla norma **ISO/IEC 42001:2023** — Sistema di Gestione dell'Intelligenza Artificiale (AIMS).  
> Include **100 punti di controllo**: requisiti del sistema di gestione (Clausole 4–10) + controlli dell'Allegato A + linee guida operative dell'Allegato B.

---

## Metodologia

- **Numerazione Consecutiva:** 1–100
- **Opzioni di Risposta:** 1) Conforme, 2) Parzialmente Conforme, 3) Non Conforme, 4) Non Applicabile
- **Campi Obbligatori:** Note descrittive per le evidenze e campo per caricamento allegati
