To generate the binary .mo file from the .po file, run:
  msgfmt gapnext-wp-it_IT.po -o gapnext-wp-it_IT.mo

Or open gapnext-wp-it_IT.po in Poedit (https://poedit.net) and save — it will compile the .mo automatically.

The .mo file must exist in this directory for WordPress to load the Italian translations.
